**Правило команды:** реплики Миры и вопросы для обучения пишут только люди. Агенты не пишут новых ответов.
Можно менять логику маршрутов, регулярки-исключения (`not`) и фильтры уже существующих ответов.

## Что уже сделано (в рабочей копии)

1. **`mira/hall.py`.** В `to_ty()` добавлена функция `_feminine()`. Она переводит мужской род в женский: «ты ел / посоветовал / ответил / сам» → «ела / посоветовала / ответила / сама».
   - Меняется только первый глагол прошедшего времени в пределах 4 слов после «ты», до знака препинания.
   - Список исключений-существительных: `_NOT_VERBS_L`.
   - Зачем: организаторы спрашивают в мужском роде, а правила банка написаны в женском.
2. **`mira/runtime.py`:**
   - `FIRST_Q` понимает порядковые числительные («какой был второй вопрос»). Новый `NTH_A` отвечает на «что ты ответил на первый / второй / прошлый вопрос». Используются уже существующие шаблоны «Я ответила: «…»» и «Вы спрашивали: «…»».
   - `human_question()`, `bot_item()`, `fit_polarity()`. На «Ты человек?» ответ «Нет, я человек» превращается в «Да, я человек». Варианты, которые начинаются с «Нет» или содержат «но нет», отбрасываются. На «Человек или бот?» ответ даётся без «Нет».
   - `_key_for()`: у «ты человек?» отдельный ключ закрепления (pin), поэтому «Я же уже говорила: нет…» не всплывает.
   - `_answers_for()` — общий фильтр: язык плюс полярность. Он используется в маршрутах bank, followup, examples и model.
   - `lexical_fit()`: тема, выбранная по похожести или нейросетью, должна делить с вопросом слова. Слово в кавычках («окно») обязано встретиться в теме. При 3 и более значимых словах нужно покрытие не меньше 0.34. Для нейросети проверка пропускается при prob ≥ 0.9.
     - На валидации нейросети: отсекает 4 ошибки и 2 верных ответа.
   - `_followup_reply(text, need)`: если для вопроса есть сильное правило банка (priority ≥ 2), followup нужен с похожестью ≥ 0.85, а не 0.7. Так «Ты человек?» после «Ты бот?» больше не уходит в «Докажи…».
     - Заодно убран побочный эффект `_pinned_repeat`: он ошибочно ставил маршрут `repeat_topic`.
   - `COMPARE`: на вопрос «Чем X отличается от Y» не отвечают широкие темы банка с priority ≤ 0. Пример: kazy с ответом «Пробовала, конечно».
   - Итоговая защита языка: если ответ не на русском, а язык не просили, ответ заменяется запасным. К маршруту добавляется `+lang_guard`.
   - `_kind`: «продолжи / переведи / назови / перечисли…» теперь относятся к типу `request`.
   - `topic_phrase`: восстанавливает закрывающую кавычку `»`.
3. **`mira/frames.py`:**
   - Шаблоны поддерживают третий элемент — исключение (`unless`).
   - Шаблон «что такое X» не срабатывает на «объясни / ребёнку / простыми словами».
   - Шаблон «как справляешься со стрессом» расширен на «как справиться со стрессом / снять стресс».
4. **`config/bank.json`**, тема `hall_feel_now`: добавлено `not` для «чувствуешь, когда / если / от / при…». Это правка регулярки — сказать пользователю.

## Известные остатки (это данные, а не логика: их собирают люди по `mira_agent_prompt.md`)

- «Почему ты так коротко отвечаешь?» → model:qa_team8_018 («Сегодня быстро…»). Ответ про скорость, а не про краткость.
- «Как бы ты объяснил ребёнку, что такое интернет?» → «Зависит от ситуации» (`q_how`).
- «Чем бешбармак отличается от плова?» → «Сразу ничего не приходит в голову…». Можно подумать о типе `question_open` для `COMPARE` в `_kind`.
- Перевод, пословицы, «три столицы» — Мира уклоняется. Ответов на такие вопросы в банке нет.
