# Mira interface directions

Three light desktop concepts generated for the matching brand directions. They
are design proposals, not implementation screenshots. The current UI and logo
stay unchanged until one direction is approved.

All three concepts show the same product state: one completed Mira response,
the next user question, and Mira thinking. They also assume a fixed application
shell, an independently scrolling transcript, and a composer pinned to the
bottom of the viewport.

## A — Cobalt + coral

- Architecture: narrow global rail + conversation pane + chat area.
- Typography: compact neo-grotesk, similar to Inter/SF Pro.
- Icons: 18–20 px outline icons on 44 px targets; filled selected state.
- Character: precise, technical, confident.
- File: `interface-a-cobalt-coral.png`.

Generation prompt summary: create a 1920×1080 light local-AI chat product using
the cobalt wave-M identity, a Primer-style split layout, compact Fluent-like
navigation states, one local-model status, a real conversation, a thinking
state, and a pinned composer. Avoid ChatGPT structure, pink/purple, decorative
cards, avatars, page scrolling, duplicate statuses, and unsupported upload
controls.

## B — Teal + mint

- Architecture: floating navigation panel + inset conversation sheet.
- Typography: humanist IBM Plex Sans-inspired scale.
- Icons: friendly rounded 16–20 px system with squared terminals.
- Character: calm, conversational, distinctive.
- File: `interface-b-teal-mint.png`.

Generation prompt summary: create a 1920×1080 light conversational workspace
using the continuous-line Mira identity, IBM Plex-inspired type, Atlassian-like
optical icon sizing, an inset fixed-height chat sheet, restrained mint states,
one completed answer, a waveform thinking state, and a pinned composer. Avoid
dual rails, blue/pink palettes, glass effects, oversized headlines, avatars,
duplicate status, and page scrolling.

## C — Amber + vermilion

- Architecture: full-width top bar + horizontal thread strip + chat stage.
- Typography: bold editorial neo-grotesk with tracked uppercase labels.
- Icons: geometric filled/outline hybrid with clear selected states.
- Character: warm, bold, independent.
- File: `interface-c-amber-vermilion.png`.

Generation prompt summary: create a 1920×1080 light editorial AI product using
the modular negative-space M, no permanent sidebar, a strict 8 px rhythm,
graphite rules, amber/vermilion accents, typographic message blocks, a modular
thinking indicator, and a flat pinned composer. Avoid bubbly dashboard cards,
cool colors, glass, gradients, avatars, duplicate status, and page scrolling.

## Research applied

- [GitHub Primer layout](https://primer.style/product/getting-started/foundations/layout/): focused content, split panes, independent scrolling, responsive ranges.
- [GitHub Primer typography](https://primer.style/product/getting-started/foundations/typography/): rem-based scale, 4 px rhythm, restrained line length.
- [IBM Carbon typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview): productive versus expressive type and IBM Plex hierarchy.
- [IBM Carbon spacing](https://www.carbondesignsystem.com/building-blocks/foundations/spacing/overview): consistent 2/4/8 spacing scale.
- [IBM Carbon icons](https://v10.carbondesignsystem.com/guidelines/icons/usage/): consistent icon sizes, monochrome hierarchy, 44 px targets.
- [Atlassian iconography](https://atlassian.design/guidelines/product/foundations/iconography/): simple metaphors, optical balance, rounded exterior and clear internal angles.
- [Microsoft Fluent iconography](https://fluent2.microsoft.design/iconography): regular and filled states for wayfinding and selection.
- [Material 3 typography](https://m3.material.io/styles/typography/applying-type): semantic display, headline, title, body, and label roles.
- [Shopify visual design](https://shopify.dev/docs/apps/design/visual-design): consistent components, selective icons, and a unified product language.
- [Apple typography](https://developer.apple.com/design/human-interface-guidelines/typography): legibility, optical sizing, adaptable hierarchy, and avoiding thin weights.
- [Apple icons](https://developer.apple.com/design/human-interface-guidelines/icons): simplified recognizable glyphs, consistent stroke and optical alignment.
