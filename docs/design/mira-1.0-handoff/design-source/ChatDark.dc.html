Убрать дубликаты в Python

Напиши функцию на Python, которая убирает дубликаты из списка, но сохраняет порядок.

Держим множество уже встреченных элементов и добавляем в результат только новые. Проверка in по множеству работает за константное время, поэтому весь проход линейный.

Если не нужна читаемость по шагам, есть однострочник: list(dict.fromkeys(items)) — словарь тоже помнит порядок вставки.
