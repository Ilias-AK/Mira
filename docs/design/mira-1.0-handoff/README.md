# Mira 1.0 — дизайн интерфейса для разработки

В этом архиве лежит новый интерфейс чата Mira в виде готового кода, который можно сразу подключать. К нему приложены логотипы, дизайн-токены, скриншоты и исходники макетов.

Фронтенд работает с тем же API, что и прежний `app.js`. На бэкенде ничего менять не нужно.

Живой макет (холст с экранами, логотипами и основой): https://claude.ai/artifact/YbV3KoUd8Uxy7uVbZo9LSC — доступ к нему выдаёт владелец.

## Быстрый старт

**Посмотреть без сервера (демо-режим):**

```bash
cd web
python3 -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000/?demo`. В демо-режиме ответы подставляются заготовками, поэтому видны все состояния интерфейса: «думает», вывод текста, код, история.

**Подключить к серверу Mira:**

1. Замените `index.html`, `app.css` и `app.js` на файлы из `web/`.
2. Скопируйте `web/assets/` в папку `/assets/` сервера. Шрифт теперь лежит в `/assets/fonts/inter-*.woff2`. Старый `InterVariable.ttf` больше не нужен.
3. Логотип раньше был файлом `/assets/mira-mark-cobalt.png`. Теперь он нарисован в разметке как SVG, поэтому PNG больше не используется.

Все пути в файлах абсолютные (`/app.css`, `/assets/...`), как и в прежней версии.

## API (не изменилось)

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| GET | `/api/status` | — | `{ ok, sessionId, maxQuestionCharacters }` |
| POST | `/api/message` | `{ message }` | `{ ok, text, seconds }` |
| POST | `/api/reset` | `{}` | `{ ok, sessionId }` |

Ошибка приходит как `{ ok: false, error: "текст" }`, и этот текст показывается пользователю.

Поле `text` в ответе можно присылать с Markdown. Поддерживаются заголовки `#`, списки `-` и `1.`, `**жирный**`, `` `код` ``, блоки ```` ```код``` ````, ссылки `[текст](https://…)` и разделитель `---`. Перед разметкой весь текст экранируется, так что HTML из ответа никогда не выполнится.

## Настройки (`CONFIG` в начале `app.js`)

```js
features: { attach: false, search: false, think: false, voice: false },
typewriter: true,
```

- `features`: кнопки «Прикрепить», «Поиск», «Подумать глубже» и «Голос» уже свёрстаны, но скрыты. Включайте их, когда бэкенд начнёт поддерживать эти функции. Состояние переключателя хранится в `aria-pressed`. Его нужно будет добавить в тело запроса, например `{ message, options: { search: true } }`.
- `typewriter`: ответ выводится постепенно, потому что API пока отдаёт его целиком. Когда появится потоковая отдача (SSE или стриминг fetch), нужно дописывать текст в `.answer` по мере прихода. Функция `typeOut()` показывает, как это сделать: на каждом кадре Markdown перерисовывается заново.

## Что уже работает

- **Пустой экран.** Приветствие зависит от времени суток (утро, день, вечер, ночь). Поле ввода стоит по центру, под ним четыре подсказки. После первого сообщения поле уезжает вниз.
- **Сообщения.** Вопрос показан в сером «пузыре», ответ идёт открытым текстом на всю колонку шириной 720 px. Пока ждём ответ, видна строка «Mira думает…» с мерцающим текстом и пульсирующим знаком.
- **Кнопка отправки** меняет три состояния: неактивна → кобальтовая «отправить» → «стоп». «Стоп» прерывает запрос или дописывает текст сразу. Esc тоже останавливает ответ.
- **Под ответом:** копировать (с галочкой после копирования), 👍 и 👎 (пока только сохраняются локально, место для отправки на сервер помечено в `setFeedback`), «Ответить заново» у последнего ответа, модель и время ответа.
- **Блок кода:** подпись языка и кнопка «Копировать».
- **История чатов.** Чаты группируются: Сегодня / Вчера / Последние 7 дней / Ранее. Есть поиск по названию и тексту, удаление чата. Сохранённый чат открывается только для чтения с пояснением, ведь сервер его контекст уже не помнит. Если сервер перезапустился, текущая переписка не пропадает, а уходит в историю.
- **Тема:** «Как в системе», «Светлая» или «Тёмная» в меню настроек. Выбор применяется до отрисовки страницы, поэтому светлая тема не мелькает при загрузке.
- **Боковая панель** на десктопе сворачивается (состояние запоминается). При ширине меньше 860 px она становится выезжающим меню с затемнением фона.
- **Горячие клавиши:**
  - ⌘K или Ctrl+K: новый чат;
  - Enter: отправить;
  - Shift+Enter: новая строка;
  - Esc: закрыть меню или панель, остановить ответ.
  
  Ввод через IME обрабатывается корректно. На телефоне Enter переносит строку, а отправляют кнопкой.
- **Обработка ошибок.** Ошибка показывается уведомлением с кнопкой «Повторить». Если сервер недоступен, в уведомлении есть кнопки «Повторить» и «Демо».
- **Кнопка «вниз»** появляется, если пользователь отлистал ленту вверх. Пока ответ печатается, лента не дёргается, если человек читает выше.
- **Доступность:**
  - у всех иконок есть `aria-label`;
  - меню размечены `role="menu"` и `aria-expanded`;
  - видимый фокус с клавиатуры;
  - контраст текста не ниже 4,5:1;
  - `prefers-reduced-motion` отключает анимации;
  - на телефоне кликабельные зоны не меньше 44 px;
  - учтены безопасные зоны iPhone (`env(safe-area-inset-*)`).

## Дизайн-принципы (их нужно соблюдать)

1. **90% нейтрального, 10% бренда.** Основа интерфейса — белый, графит и тонкие линии. Кобальт `#1F3BD6` появляется только на действиях: отправка, активный переключатель, ссылки, фокус. Коралл `#FF5A4E` используется только как «искра» в знаке и в иконках-подсказках. Не красьте фоны в синий: это и было главной проблемой прошлых версий.
2. **Ответ читается как статья.** У ответа нет «пузыря»: шрифт 16/27, заголовки 20 px. В пузыре только сообщение пользователя.
3. **Один шрифт.** Inter во всех размерах. Крупные заголовки получают сжатую разрядку (−3,5%) и оптический размер `opsz 32`, поэтому выглядят «дисплейно», как SF Pro у Apple.
4. **Одна толщина иконок:** линии 1,75 px, иконка 20 px, кнопка вокруг неё 40 px (на телефоне 44 px).
5. **Скругления из шкалы:** 8 / 10 / 12 / 20 / 22 (пузырь) / 26 (поле ввода) / круг. Других значений не вводить.
6. **Цвета только через токены.** В коде не должно быть ни одного «голого» HEX вне блока токенов в `app.css`. Тёмная тема получается переопределением тех же переменных.

## Логотип

Основной знак — **01 «Арка»**: строчная «m» и коралловая точка, читается как «Mira.».

| Файл | Где использовать |
|---|---|
| `mira-mark.svg` | на светлом фоне |
| `mira-mark-on-dark.svg` | на тёмном фоне (кобальт осветлён до `#8C9BFF`) |
| `mira-mark-on-cobalt.svg` | на кобальтовом фоне (белая «m») |
| `mira-mark-mono-*.svg` | одноцветная печать, гравировка |
| `mira-lockup*.svg` | знак со словом. В SVG слово набрано текстом шрифтом Inter. Для печати и стороннего использования переведите его в кривые. |
| `app-icon/` | иконка приложения: кобальтовый фон, белая «m». Скругление углов добавляют iOS и Android сами, в файле квадрат. |

Правила:

- свободное поле вокруг знака — не меньше высоты коралловой точки × 2;
- минимальный размер — 16 px;
- знак нельзя вращать, обводить, класть на градиенты и перекрашивать точку.

## Что дальше (не входит в этот пакет)

- **Потоковая отдача ответа (SSE).** Это самое заметное улучшение «живости».
- **Подсветка синтаксиса в коде.** Подойдёт Shiki или Prism. Цвета берите из макета тёмной темы: ключевые слова `#FF8A7D`, функции `#9AA8FF`, встроенные `#E5C07B`, числа `#F2B880`, комментарии `#7C7F88`.
- **История на сервере.** Сейчас она хранится в `localStorage` браузера, а сессия — в `sessionStorage`.
- **Включение функций по готовности бэкенда:** вложения, голосовой ввод, поиск, режим «подумать глубже», память с плашкой «Память обновлена» (её макет есть на холсте, экран «iPhone — диалог и память»).
- **Таблицы в Markdown-ответах.** Как они должны выглядеть, показано на холсте, экран «Десктоп — диалог».

## Исходники макетов

В `design-source/` лежат артборды холста в формате `.dc.html`. Это справка для сверки отступов и текстов. Сами по себе они не открываются, им нужна среда холста. Чтобы посмотреть экраны вживую, откройте ссылку на холст в начале этого файла.
