These are generated exploration boards, not production logo files. The current
logo remains unchanged until a direction is approved and redrawn as clean SVG.

- Confident, technical, energetic.
- Strongest at competition-demo scale.

## B — Teal + mint

- Calm, conversational, more distinctive than a typical AI brand.

- Warm, bold, editorial.
- Feels less like an AI utility and more like an independent product.
- Primary: `#20201E`; accents: `#F4B942` and `#F05A3C`.
