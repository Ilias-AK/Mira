# Генерация данных для Миры (26.11)

Промпты в `prompts/` самодостаточные: агенту не нужен ни доступ к файлам, ни контекст проекта. Скопируйте весь текст файла в нового агента и отправьте. Агент выдаёт данные партиями. Пишите ему «дальше», пока не наберётся нужный объём.

Перед запуском проверьте раздел «Б» в `CANON.md`: это новые факты биографии, которые получат все агенты. Если с каким-то пунктом не согласны, вычеркните его в каждом промпте (раздел «Б. Дополнительные факты»).

Все партии от одного агента складывайте в один файл подряд. Строки с `#` программа пропускает.

Важно:
- Агент закрытого теста (10) не должен видеть ничего из остальных: отдельный чат, отдельный агент.
- Перед импортом прогоните `python -m mira.check_gen data/team_raw/hall_qa_gen_*.txt data/team_raw/paraphrases_gen_*.txt`. Ошибки (ERROR) нужно убрать, предупреждения (WARN) — просмотреть.
- Всё сгенерированное лежит в файлах с `gen` в имени. Если организаторы спросят о происхождении данных, видно, что откуда. При необходимости эти файлы убираются одной командой.
- Можно просто прислать мне готовые файлы: я проверю, встрою, переобучу и сравню на закрытом тесте и вопросах людей.
