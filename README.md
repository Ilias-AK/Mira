# Мира — бот для «Тьюринг-арены» (ITFEST)

Мира — студентка ЕНУ, которая отвечает на вопросы зала из-за ширмы. Задача — чтобы зрители не смогли отличить её от двух живых участников.

Бот работает полностью офлайн и соблюдает правила конкурса: в нём нет готовых языковых моделей, чужих весов и внешних API. Нейросеть обучена командой с нуля, ответы написаны людьми из команды, а выбирает их программа.

## Запуск (Windows, Python 3.11)

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File .\mira\run_mira.ps1
```

Или двойной щелчок по `start_mira.bat`. По умолчанию включён режим конкурса: ответы на русском, не больше 300 символов, обращение на «вы».

Ключи `run_mira.ps1`: `-Chat` — обычный чат, `-ShowTime` — показывать время ответа, `-NoTypos` — без редких опечаток.

### Веб-интерфейс

Красивый локальный интерфейс запускается двойным щелчком по `start_mira_ui.bat` или командой:

```powershell
powershell -ExecutionPolicy Bypass -File .\mira\run_ui.ps1
```

Он автоматически откроется по адресу `http://127.0.0.1:8765`, работает без интернета и обращается напрямую к `MiraRuntime`. Полезные параметры: `-Chat` — обычный стиль переписки, `-Typing` — человеческая пауза перед ответом, `-NoTypos` — отключить редкие опечатки, `-Port 9000` — другой локальный порт.

## Как устроена Мира

Каждый вопрос проходит цепочку шагов. Первый шаг, который уверенно понял вопрос, даёт ответ:

1. **Память разговора** (`mira/dialog_memory.py`, `mira/user_facts.py`): имя собеседника, его питомцы, город, загаданные слова, «повтори мой прошлый вопрос».
2. **Уточнения из цепочек команды** («Дальше:» в `data/team_raw/hall_qa_*.txt`).
3. **Арифметика, время, счёт предметов** (`mira/word_problems.py`).
4. **Правила и анкета** (`build/*.py` → `config/bank.json`, `config/persona.json`).
5. **Собственная нейросеть тем** (`mira/intent_model.py`): трансформер-кодировщик, обученный командой с нуля, плюс классификатор тем банка.
6. **Похожие вопросы команды**: сравнение по символьным триграммам.
7. **Запасные ответы по типу вопроса**, в которых повторяется тема, названная собеседником.

Подробности, происхождение данных и правила для команды — в `mira/README_MIRA.md`.

## Модели

- `runs/mira_intent/intent.pt` (43 МБ) — нейросеть тем, которую использует бот. Её достаточно для запуска.
- `runs/main/dialogue/best.pt` (~250 МБ) — базовый кодировщик-декодировщик, обученный с нуля. Нужен только для переобучения нейросети тем (`mira/train_intent.ps1`). В GitHub не помещается (лимит 100 МБ), выкладывается отдельно.
